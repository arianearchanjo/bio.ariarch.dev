# ariarch.dev — Link in Bio

Página de links (Linktree style) personalizada, com design moderno, arredondado e interativo.

## ✨ Destaques
- **Design de alto nível:** Focado em tipografia (Syne e Space Mono) e acabamento refinado.
- **Serviços Explicativos:** Modais interativos que explicam termos técnicos para pequenos negócios.
- **Formulário Inteligente:** Captura de leads via WhatsApp com mensagens pré-formatadas.
- **Status Ativo:** Indicador visual de disponibilidade para novos projetos.
- **100% Responsivo:** Experiência otimizada para dispositivos móveis (Bottom Sheets).

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 (Vanilla) com Flexbox/Grid
- JavaScript Nativo
- Google Fonts (Syne & Space Mono)

## 🚀 Como usar
Basta abrir o arquivo `index.html` em qualquer navegador ou hospedá-lo em serviços como Vercel, Netlify ou GitHub Pages.
